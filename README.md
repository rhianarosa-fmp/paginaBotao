Projeto: Cartão Interativo

Descrição:
Este projeto consiste na criação de um cartão interativo utilizando HTML, CSS e JavaScript. O objetivo é praticar a estruturação de páginas, estilização e manipulação de elementos através de cliques.

 Tecnologias utilizadas:
- HTML5
- CSS3
- JavaScript

 Funcionalidades:
- Cartão centralizado na tela.
- Botão para destacar o cartão.
- Alteração do título e da mensagem após o clique.
- Segundo botão para voltar ao estado inicial.
- Contador que mostra quantas vezes o botão de destaque foi clicado.

 Organização dos arquivos:
- `index.html`: estrutura do cartão.
- `style.css`: cores, centralização e aparência.
- `script.js`: funções dos botões e contador.

 Objetivo:
Praticar conceitos básicos de HTML, CSS e JavaScript, aprendendo a criar uma página interativa e modificar elementos através de ações do usuário.
